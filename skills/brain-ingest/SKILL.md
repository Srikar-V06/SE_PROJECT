# brain-ingest

## Steps
1. Read AGENTS.md for the schema and naming rules.
2. Put the raw source in brain/inbox/ if needed.
3. Write the note in brain/resources/ with full frontmatter.
4. Sections: Summary, Key points, Relevance to this project.
5. Add at least one [[wikilink]] to another note.
6. Add the note to brain/index.md.
7. Add a line to brain/log.md: date | ingest | note-name
8. List sources in the frontmatter. Do not invent facts.
