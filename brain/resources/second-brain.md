## Summary
A second brain is a personal knowledge system kept outside your head, so notes are easy to find and reuse. Obsidian implements this with plain Markdown files linked together. PARA is a simple way to organize those files by how actionable they are.

## Key points
- Notes are plain Markdown files stored locally in a folder (a vault).
- Wikilinks connect notes, and backlinks show what links to a note.
- Frontmatter (properties) stores metadata like type, status and tags.
- PARA: Projects (active work with deadlines), Areas (ongoing responsibilities), Resources (reference topics), Archive (inactive items).
- index.md is the entry point and log.md records what was added or changed.
- An AI agent can maintain the vault by following a schema file (AGENTS.md) and skills.

## Relevance to this project
The brain/ folder is the shared memory for the team and the AI agent. It keeps decisions, research and project knowledge in one structured place, and it follows the PARA layout required by the SDLC document. Skills like [[agent-skills]] are used to maintain it, under the rules in [[ai-policy]].
