## Summary
A second brain is a personal knowledge system kept outside your head, so notes are easy to find and reuse. Obsidian implements this with plain Markdown files linked together. PARA is a simple way to organize those files.

## Key points
- Notes are plain Markdown files stored locally in a folder (a vault).
- [[wikilinks]] connect notes, and backlinks show what links to a note.
- Frontmatter (properties) stores metadata like type, status and tags.
- PARA: Projects (active work), Areas (ongoing responsibilities), Resources (reference topics), Archive (inactive items).
- index.md and log.md give a map and a history of the brain.

## Relevance to this project
The brain/ folder is the shared memory for the team and the AI agent. It keeps decisions, research and project knowledge in one structured place.
