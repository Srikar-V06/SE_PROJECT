# ADR-002: Integer minor units for money
Status: Accepted | Date: 2026-11-19 | Author: BharathVikas-T

## Context
Floating-point numbers cannot represent most decimal amounts exactly, and money
must be exact (SRS C-2, NFR-16).

## Decision
Store and compute all money as integers in minor units (paise or cents).
The API accepts only strict JSON integers; decimal text exists only in the UI.

## Alternatives considered
- float: rounding errors.
- Decimal/NUMERIC types: exact, but SQLite has no native decimal type.

## Consequences
- Exact arithmetic everywhere; tests must reject 10.5, 100.0, 1e3, strings, booleans.
- The UI converts "100.50" to 10050 using string logic.
